\# PLP Python Week 3 Assignment



This repository contains Python programs for Week 3:



\- \*\*name\_greeter.py\*\*: Greets users by their first name when provided a full name.

\- \*\*bug\_hunt.py\*\*: Identifies and fixes bugs in basic arithmetic and greeting logic.

\- \*\*ticket\_checker.py\*\*: Determines ticket eligibility and price based on user age.



\## Setup \& Running

Run any script using Python 3:

`python name\_greeter.py`
